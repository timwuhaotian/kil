Why Kil

Four things Kil does that other macOS terminals don't do together.

Jobs survive quit — even crash

A session server holds every pane's terminal. ⌘Q, closing the window, or a crash only detaches; the next launch reattaches to the same live processes with full screen, scrollback, and input modes.

8.6 MB installed

Smaller than Alacritty (14.7 MB) — which has no tabs or splits — and over 100× smaller than Warp (913.7 MB). Native Metal rendering via GPUI, VT parsing via alacritty_terminal.

0% CPU at idle

A window with nothing to draw doesn't wake. A blinking cursor redraws only itself, and nothing is written to disk unless something changed.

Phone remote via Agent on Edge

Scan a QR code to pair an iPhone to the same session server over a TLS tunnel — the panes on the phone are the panes on the desk. Optional UPnP port forwarding, no cloud service involved.

Frequently asked questions

Short answers, with the numbers.

What is Kil?

Kil is a native macOS terminal written in Rust, built on GPUI (Metal rendering) and alacritty_terminal (VT parsing). It has vertical tabs, animated split panes, and rebindable shortcuts, installs at 8.6 MB, and runs on Apple silicon with macOS 14 or later.

How do my sessions survive quit or crash?

A small session server (kil --server, the same binary) holds every pane's terminal and owns its PTY and child process. Pressing Cmd+Q or closing the window only detaches from it, and so does a crash. The next launch reattaches to the same live processes with the full screen, scrollback, and input modes — vim's unsaved buffer, the ssh connection, and the half-finished build are where you left them.

What happens after a logout or reboot?

Kil saves the layout, each pane's directory, and the window frame within 2 seconds of a change, and each pane's screen and scrollback every 30 seconds while it prints, plus immediately on quit. After a logout or reboot the processes themselves are gone, so each pane's last job is typed into a new shell instead.

How big is Kil compared to other macOS terminals?

Kil installs at 8.6 MB, measured at version 0.0.10. For comparison: Alacritty 14.7 MB, Ghostty 65.0 MB, iTerm2 202.9 MB, kitty 253.0 MB, and Warp 913.7 MB. Alacritty is the only one near Kil's size, and it has no tabs or split panes.

Does Kil use CPU when idle?

No. A window with nothing to draw doesn't wake: zero CPU at rest, and a blinking cursor redraws only itself. Nothing is written to disk unless something changed.

How do I install Kil, and what does it cost?

Kil is free and MIT-licensed. Download Kil-arm64.dmg (always the latest build), open it, and drag Kil to Applications. The app is signed with a Developer ID and notarized by Apple. From then on it keeps itself up to date: it checks at launch and every 6 hours, verifies checksum, signature, and notarization, and jobs keep running across the update.
